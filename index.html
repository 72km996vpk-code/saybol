3. 计算规则

为了方便你称重，默认按以下口径估算：
  • 肉类、虾、鸡蛋和蔬菜：下锅前生重。
  • 意大利面、荞麦面：干重。
  • 即食米饭：包装标注的熟重。
  • 油和调料也计入估算；品牌、部位和烹饪损耗会带来误差。
鸡肉、鸡腿肉等禽肉要彻底熟透；有食品温度计时，中心温度达到 74°C 更稳妥。

候选食谱

我的收藏

收藏内容保存在当前浏览器里。清理浏览器数据或换设备后可能不会保留，建议定期导出备份。

备份与恢复

食材、目标、收藏菜谱会自动保存在当前设备的浏览器中，不会自动同步到其他设备。

恢复默认食材与目标

这不会删除已收藏菜谱。只会恢复常用食材选择和默认目标。

数据说明

此页面是单文件静态网页。食材与收藏仅存储在当前浏览器 localStorage；不会自动上传到 GitHub 或云端。导出 JSON 可以备份、迁移。

食谱热量和营养为估算值，仅供日常饮食参考。
